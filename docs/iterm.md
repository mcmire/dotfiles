# iTerm

I'm using these Settings for iTerm:

- **General**
  - Reuse previous session's directory
- **Colors**
  - (Managed by Tinty)
- **Text**
  - **Thin strokes:** On Retina displays
  - **Font:** Cascadia Code, 14pt
  - **Line height:** 1.19
  - **Letter spacing:** 0.88
  - **Use ligatures:** Yes
  - **Use a different font for non-ASCII text:** Symbols Nerd Font Mono, 14pt
- **Window**
  - **New windows:** Maximized
- **Terminal**
  - Unlimited scrollback
